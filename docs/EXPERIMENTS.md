# 参数整定与实验记录

## 为什么有这张表

`config/charge_params.yaml` 里每一个阈值都是现场调出来的。但「调之前是多少、凭什么定这个值、试过别的没有」，
如果只留在脑子里，三个月后自己说不清，别人更没法复用。

每次改参数 → 存一份快照 → 在这里加一行。**快照是证据，这一行是结论。**

## 使用方式

1. 改完 `config/charge_params.yaml`，先跑一次快照脚本：

   ```bash
   bash scripts/snapshot_params.sh
   ```

   它会把当前参数原样存到 `experiments/<时间戳>/params.yaml`，并记下当时的提交号和分支。

2. 在下面的记录表里加一行，填「场景 / 指标 / 结论」。

3. 提交时把 `config/`、`experiments/`、本文档放在**同一次提交**里。
   分开提交会让「哪版参数对应哪次实验」对不上，这张表就废了。
